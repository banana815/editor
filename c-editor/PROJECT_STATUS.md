## 0.3.1 本轮改动与验证

- 写作工作区：默认保留常用操作，完整格式栏按需展开；宽窗口限制正文列宽，侧栏使用“文章库”组织笔记。
- 专注模式：隐藏侧栏和格式控件，保留退出入口；`Ctrl/Cmd+Shift+F` 切换，`Esc` 退出，不修改正文。
- 文章大纲：侧栏显示当前文档的 H1–H6 标题，点击跳转；`Ctrl/Cmd+Shift+O` 切换大纲与文章库，`Ctrl/Cmd+Shift+T` 展开或收起格式栏。
- 标题输入：`Ctrl/Cmd+Alt+1` 至 `6` 设置 H1–H6，`0` 恢复正文。在顶层正文段落开头键入一至六个 `#` 后再输入空格可转换为对应标题，单步撤销可恢复前缀；粘贴与 IME 预编辑不触发转换。
- 列表按钮：所选段落均为同类列表时再次点击会取消列表，否则应用所选类型。仍通过候选文档提交，无法安全保留元数据时整次失败并保留原文。
- 写作统计：状态栏按全文或选区显示非空白字符、估算词数、非空文本段落与阅读时间。字符按 Unicode 标量计数，并非字素簇；组合字符及 emoji 序列可能计为多个字符，隐藏格式控制符与引用占位符不计入。词数将中日韩字符分别计为单位，其他字母/数字连续段合并；阅读时间按每分钟 200 单位向上取整，仅供写作估算。
- 发布：版本及平台构建号统一为 0.3.1 / 4；应用工作流接受 `v0.3.1` 等与 CMake 版本一致的标签，所有应用构建、测试与启动检查通过后才发布 Pre-release。附件包括三个桌面包、未签名 Android APK、未签名 iOS 设备/模拟器包、Web 包及 SHA256 校验文件。

首轮 v0.3.0 标签的浏览器测试因展开工具栏改变了测试焦点而失败，未发布 Release。修正测试为保持焦点的键盘操作后，在同一 WASM 产物上完成编辑、触摸和慢速文献测试；使用新标签 v0.3.1 重新验证发布，不改写旧标签。

本轮不包含博客服务直接发布或新的出版级 HTML 导出。现有文献功能、旧数据导入、网络必须由明确操作触发以及启动不自动刷新来源的合同保持不变。

## 目标与实现边界

目标平台为 Windows、macOS、Linux、Android、iOS 和浏览器，保留编辑器、笔记存储与 Zotero 工作流。应用、文档、存储、文献数据和引用处理使用 C11，不内嵌 JavaScript 引用处理器。

SDL3 负责窗口和输入。Objective-C、Java/JNI、浏览器 JavaScript 仅连接平台能力，例如文件选择、网络传输、剪贴板和持久化；文本整形依赖包括具有 C 接口的 HarfBuzz，其内部使用 C++。具体依赖和许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。因此这里的“C 重写”不表示操作系统接口和全部第三方库的源码都只有 C。

## 已完成内容

- 文档：富文本、标题、列表、对齐、链接、搜索、撤销/重做、IME、emoji、自动保存，以及 HTML、TipTap JSON 和旧笔记导入。旧文件导入为新副本，保留原文件与可保留的未知元数据。
- 跨平台交互：桌面与移动布局、触摸滚动/选区/菜单、带格式剪贴板、浏览器持久化与导出。复制引用携带来源快照；粘贴修复重复引用 ID，并与书目一起提交为一次撤销。
- 文献库：CSL JSON、只读 Zotero SQLite/WAL、分类和检索、跨文献库身份、页码与摘录、条目/PDF 链接、本地缓存。
- 引用：纯 C 处理器连接固定版本 APA 7、IEEE 2023 和 GB/T 7714-2015 顺序编码制样式，处理排序、编号、消歧和结构化参考文献。导入的显示缓存不作为可信输出，打开时根据来源重新生成。

2026-11-15 以前的更新包含：

- 列表增加/减少缩进，包含列表内标题的 Tab/Shift+Tab；完整清除格式，保留未选中文字的原格式和不可丢弃的元数据。
- 旧独立书目以“旧存档”显示，并提供安全的文字复制；显示旧内容不等于把旧 HTML 转换成新的完整 CSL 来源。
- 文献多选、勾选筛选结果、独立书目生成。使用 `bibliographyMode: "selected"` 和 `selectedItemsJson` 保留明确选择的来源；与正文引用取并集，不制造虚假引用块。
- 独立书目的 JSON/HTML 往返、剪贴板合并、样式切换及单步撤销。来源冲突和不可安全合并的未知属性会使整次操作失败，保留原文。
- HTTP(S) 来源连接、取消和手动刷新，以及桌面 SQLite 来源重新读取。数据解析成功后才替换原文献库；来源设置与对应缓存共同保存，启动时不自动联网。
- 打开文献面板时把选中文字带入摘录。来源刷新会等待正在编辑的引用页码/摘录提交，避免把输入写入错误草稿。

与原应用直接对照，以下编辑体验差异仍未完成：

1. 连续相邻输入按约 500ms 合并撤销；目前每次输入事件独立入栈。
2. 光标位于已有链接内时，预填并修改/移除整段链接；目前空选区仅设置后续输入链接。
3. 桌面鼠标双击选词、三击选逻辑段落，以及按词/段拖动扩展选择。
4. 原有对齐快捷键。

旧清单中的“再次点击同类列表按钮取消列表”与“H1–H6、对应快捷键、Markdown 标题输入规则”已在 0.3.1 实现；验证状态见本轮检查表。

其他验收边界：完整富文本双向排版、其他浏览器、手机实体键盘/输入法/生命周期/文件提供器、移动签名与更新、无障碍及发行许可核查仍未完成。当前固定样式和代表性测试不构成完整 CSL 或 APA/IEEE/GB 标准符合性证明；不支持的活动构造会明确报错。Zotero 字段映射的再分发依据也仍列在第三方说明中待核查。
