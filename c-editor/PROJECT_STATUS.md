## 0.4.0 六项写作能力

1. **基础编辑。** 500ms 内连续相邻的普通输入可合并撤销；移动、选区、格式、删除、IME 和保存边界结束合并。已有链接可通过单击后的编辑框或 `Ctrl/Cmd+K` 预填修改，留空移除链接并保留其他样式。鼠标双击选词、三击选逻辑段落，可按相应单位拖动扩展。
2. **文章组织。** “管理”提供逻辑单层文件夹、自由文本标签、置顶，以及“草稿 / 待修改 / 已发布”状态。文件夹不会移动磁盘文件，也不构成嵌套目录树；文件夹和状态精确筛选，标签按区分大小写的子串筛选。“已发布”只是本地状态，不会上传博客。
3. **复制与导出。** “复制MD / 复制HTML”复制整篇文章的源码；“导出MD / 导出HTML”生成真实 `.md` / UTF-8 `.html` 文件，原 JSON 导出保留。HTML 复制为正文片段，文件含 charset 和文档外壳；Markdown 对复杂标记、对齐及引用使用 HTML。引用和书目从权威来源重新计算，导入的显示缓存不作为依据。不支持的结构、格式和不安全链接会明确失败。发布输出省略来源元数据，不能替代 JSON 备份；浏览器复制需要获得授权的用户操作，失败可改用文件导出。本轮没有博客服务直接发布。
4. **查找与替换。** 当前文章支持替换下一处、全部替换，一次操作一次撤销；仅支持单行字面匹配，ASCII 字母忽略大小写，其余 UTF-8 精确匹配，不跨段落或原子引用块，也不递归替换新插入文本。跨文章搜索正文，每篇显示首个匹配的摘要并可跳转；当前文章采用未保存内容，其他文章读已保存版本。无法读取的文件会计数提示；不支持正则或完整 Unicode 大小写折叠。
5. **专注与目标。** 保留专注模式、打字机定位，新增段落聚焦，以及每篇文章 0–10000000 非空白字符目标（0 关闭）。字符按 Unicode 标量计数，不是字素簇，忽略隐藏格式控制符和引用占位符；选区统计不改变全文目标进度。词数与阅读时间仍是估算，不能解释为语言分词或每日写作量。
6. **历史与回收。** 首次修改保存前，以及后续保存间隔达到 60 秒时，保存上一个磁盘版本，重复内容去重；不是每次按键记录，也不是对未保存内容定时拍快照。历史预览不修改正文，恢复前保留当前已保存内容，恢复操作可以撤销。删除先写回收副本，再删原文件；回收站预览后恢复为未占用的名称，回收副本继续保留。数据位于笔记根目录的 `.notelab-writing/`，不自动清理，不是云备份；浏览器仍需完成持久化刷新。

快捷键：`Ctrl/Cmd+Shift+M` 文章管理，`Ctrl/Cmd+H` 替换，`Ctrl/Cmd+Shift+H` 全部替换，`Ctrl/Cmd+Shift+P` 搜索文章。原有专注、大纲、格式栏快捷键分别为 `Ctrl/Cmd+Shift+F/O/T`；`Ctrl/Cmd+Alt+1…6` 设置 H1–H6，`0` 恢复正文。Markdown 标题输入及再次点击同类列表取消列表继续可用。

## 目标与实现边界

目标平台为 Windows、macOS、Linux、Android、iOS 和浏览器，保留编辑器、笔记存储与 Zotero 工作流。应用、文档、存储、文献数据和引用处理使用 C11，不内嵌 JavaScript 引用处理器。

SDL3 负责窗口和输入。Objective-C、Java/JNI、浏览器 JavaScript 仅连接平台能力，例如文件选择、网络传输、剪贴板和持久化；文本整形依赖包括具有 C 接口的 HarfBuzz，其内部使用 C++。具体依赖和许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。因此这里的“C 重写”不表示操作系统接口和全部第三方库的源码都只有 C。

## 已完成内容

- 文档：富文本、标题、列表、对齐、链接、搜索、撤销/重做、IME、emoji、自动保存，以及 HTML、TipTap JSON 和旧笔记导入。旧文件导入为新副本，保留原文件与可保留的未知元数据。
- 跨平台交互：桌面与移动布局、触摸滚动/选区/菜单、带格式剪贴板、浏览器持久化与导出。复制引用携带来源快照；粘贴修复重复引用 ID，并与书目一起提交为一次撤销。
- 文献库：CSL JSON、只读 Zotero SQLite/WAL、分类和检索、跨文献库身份、页码与摘录、条目/PDF 链接、本地缓存。
- 引用：纯 C 处理器连接固定版本 APA 7、IEEE 2023 和 GB/T 7714-2015 顺序编码制样式，处理排序、编号、消歧和结构化参考文献。导入的显示缓存不作为可信输出，打开时根据来源重新生成。

2026-11-15 以前的更新包含：

- 列表增加/减少缩进，包含列表内标题的 Tab/Shift+Tab；完整清除格式，保留未选中文字的原格式和不可丢弃的元数据。
- 旧独立书目以“旧存档”显示，并提供安全的文字复制；显示旧内容不等于把旧 HTML 转换成新的完整 CSL 来源。
- 文献多选、勾选筛选结果、独立书目生成。使用 `bibliographyMode: "selected"` 和 `selectedItemsJson` 保留明确选择的来源；与正文引用取并集，不制造虚假引用块。
- 独立书目的 JSON/HTML 往返、剪贴板合并、样式切换及单步撤销。来源冲突和不可安全合并的未知属性会使整次操作失败，保留原文。
- HTTP(S) 来源连接、取消和手动刷新，以及桌面 SQLite 来源重新读取。数据解析成功后才替换原文献库；来源设置与对应缓存共同保存，启动时不自动联网。
- 打开文献面板时把选中文字带入摘录。来源刷新会等待正在编辑的引用页码/摘录提交，避免把输入写入错误草稿。
